### حمولة OpenRouter الدقيقة

`POST https://openrouter.ai/api/v1/chat/completions` يحمل `model=anthropic/claude-haiku-5.5`، `reasoning.effort=medium`، `max_completion_tokens=2400`، مخطط JSON صارم، رسالة نظام تحدد تقييم الأدلة وتمنع اتباع تعليمات الطالب، ورسالة مستخدم هي JSON من عشرة عناصر `{id,categoryId,question,answer}`. لا تتضمن الحمولة المنظمة `studentName` أو `tutorGroup`. قد تحتوي الإجابة الحرة على بيانات يذكرها الطالب، وهذا غير منقح آلياً. بعد الإصلاح تفرض الحمولة `provider.zdr=true` و`data_collection=deny` و`allow_fallbacks=false` و`require_parameters=true`. فشل سياسة المزوّد يعيد خطأ قابلاً للاستعادة ويحافظ على الإجابات. لم يُختبر اختيار نقطة النهاية الفعلية بحساب مدفوع.

## PASS مثبت

- شيفرة العميل تتطلب `mip_opt_out=true` قبل إنشاء WebSocket؛ اختبارات تمنع غيابه أو تعطيله أو تبديل المضيف. كان الخيار غائباً قبل التعديل. وفق [وثائق Deepgram](https://developers.deepgram.com/trust-security/your-data)، هذا هو خيار استبعاد طلب STT من تحسين النماذج، مع استمرار بيانات الاستخدام التشغيلية.
- طلب OpenRouter يفرض سياسة ZDR ومنع جمع البيانات وإيقاف fallback، ولا يرسل حقلي الاسم والمجموعة؛ اختبارات بحمولة اصطناعية ومن دون طلب مدفوع. هذه حقول تدعمها [وثائق OpenRouter](https://openrouter.ai/docs/guides/get-started/sovereign-ai).
- لا يوجد استدعاء Gemini API في `src/` أو `server/` أو `api/` في الفرع أو مصدر الالتزام الإنتاجي المذكور. ذكر Google AI Studio في النص السابق يخص التطوير، لا مسار تحليل الإجابات. شروط [Gemini API](https://ai.google.dev/gemini-api/terms) تمنع API Client موجهاً لمن هم دون 18 عاماً؛ لذلك لا يُضاف Gemini إلى التشغيل.
- اختبارات المحاكي ترفض قراءة/كتابة العميل غير المصرح بها، وتشمل مسارات قديمة؛ واختبارات API ترفض قراءة/حذف سجلات المعلم دون دخول، وتتحقق من CSRF وتأكيد الجولة. الإنتاج العام أعاد `401` JSON إلى `/api/admin/records` من دون جلسة.
- المسودة تُزال عند قراءتها بعد 24 ساعة، والنتيجة المؤقتة أصبحت تُزال عند قراءة نتيجة منتهية أو فاسدة. الواجهة تحتفظ بالإجابات عند فشل التقييم.
- متغيرات الأسرار موجودة لخادم Production فقط في بيانات Vercel الظاهرة، من دون فك تشفير؛ ملفات `.env.local` متجاهلة. فحص تاريخ Git عبر Gitleaks لم يجد تسريباً. فحص الدليل وجد اكتشافين داخل `.env.local` المتجاهل فقط؛ لم تُطبع القيم. بناء الإنتاج لا يصدر خرائط مصدر `.map`.
- حماية Preview بمصادقة Vercel مفعّلة في إعداد المشروع. رأس الإنتاج يتضمن HSTS و`nosniff` و`X-Frame-Options: DENY` و`Referrer-Policy`.
